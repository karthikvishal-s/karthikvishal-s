### Selected work

- **[Knock](https://github.com/karthikvishal-s/Knock)** — Log an expense by double-tapping the back of your iPhone. SwiftUI, SwiftData, App Intents, widgets. 111 unit tests.
- **[Zenith](https://github.com/karthikvishal-s/Zenith)** — Config and feature-flag engine in Go. Gin, GORM, Postgres, Docker.
- **[Flash Sale Engine](https://github.com/karthikvishal-s/flash-sale-engine)** — No oversells under load: atomic stock checks in Redis/Lua, SQS buffering, idempotent workers.
- **[Vigilance](https://github.com/karthikvishal-s/Vigilance)** — Real-time fraud detection. XGBoost behind FastAPI, Streamlit for monitoring.
- **[Journal](https://github.com/karthikvishal-s/Journal)** — Encrypted macOS journal with no network access. Swift, CryptoKit, no dependencies.
- **[LithoFlow](https://github.com/karthikvishal-s/LithoFlow-Firmware)** — Smart bottle: ESP32, a load cell, and a TFLite model that tells sips from bumps ([model](https://github.com/karthikvishal-s/LithoFlow-EdgeML)).
- **[TealSlate](https://github.com/karthikvishal-s/TealSlate)** — Motion-heavy studio site. React, GSAP, Lenis. [Live](https://teal-slate.vercel.app).
- **[Fabergé](https://github.com/karthikvishal-s/Faberge)** — Turns a short quiz into a Spotify playlist using Gemini. Next.js, Flask.

Also: [ClauseAI](https://github.com/karthikvishal-s/ClauseAI), [SyncHRMS](https://github.com/karthikvishal-s/SyncHRMS), [Le Marché](https://github.com/karthikvishal-s/Le-Marche-Frontend), [Vanguard](https://github.com/karthikvishal-s/Vanguard), [PatternSlayer](https://github.com/karthikvishal-s/PatternSlayer), [The Raven's Roost](https://github.com/karthikvishal-s/The-Ravens-Roost), [Pensieve](https://github.com/karthikvishal-s/Pensieve), [Movie Recommender](https://github.com/karthikvishal-s/Recommendation_System).
